本模块由三层组成：`eng/Verify.ps1` 是产品本地 CI 入口，按 Debug/Release 两种配置依次执行 `restore --locked-mode`、`build`、可选 `test`（输出 TRX）、`pack`，并将产物复制到仅引用 NuGet feed 的隔离消费者目录中运行，拒绝项目源依赖混入；`.github/workflows/verify.yml` 在 `windows-latest` 上以矩阵方式调用该脚本，产出到 `$env:TEMP/validation-*` 并生成 `result.json`；`docs/VERIFICATION.md` 记录 Source 与 Package 两种恢复模式的手动验证步骤、平台限制（Apple 原生需匹配主机）以及 Mode-isolated NuGet lock 对比流程；`docs/provenance/` 通过 `extraction.json`、`commit-map.txt` 和许可证文件维护上游依赖的版本映射与许可证证据。依赖方向单向：CI → 脚本 → dotnet CLI → 产物与日志，不反向引用源码工程。
