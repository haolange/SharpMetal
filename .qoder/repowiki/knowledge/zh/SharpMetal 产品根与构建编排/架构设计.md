根目录以 `Directory.Build.props` / `Directory.Build.targets` 作为所有子项目的共同入口：导入 `SharpMetal.product.props` 声明产品名称，并引入可选的 `stack.local.props` 注入本地源路径；集中定义 `StackReferenceMode`（Source/Package）、`BaseOutputPath`、`BaseIntermediateOutputPath`、`RestorePackagesWithLockFile` 以及按项目名、模式、平台、RID 隔离的 artifacts 布局。`Directory.Build.targets` 在 `ValidateStackReferenceMode` 中强制 Source 与 Package 互斥、禁止隐式回退到包、校验 `StackProduct` 引用的源仓库存在性，并通过 `PreserveStackProductProjectReferenceConfiguration` 把 Configuration/Platform/RID 透传到项目引用图，使整个依赖图共享同一依赖解析策略。`global.json` 锁定 .NET SDK 10.0.100，DESIGN.md 规定产物、锁文件命名（`packages.<Mode>.<RID>.lock.json`）与边界契约，AGENTS.md 约束贡献行为；docs_and_verification 子模块基于这些约定执行构建、测试、打包与发布证据收集，形成“根层契约 → 子模块实现”的双向耦合。
